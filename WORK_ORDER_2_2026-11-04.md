After Task E, the next modules are l1_mesi_ctrl and dir_ctrl. Build them TOGETHER, not separately:

Mandatory behaviours, from the ruled spec — do not paraphrase them from memory, read them:
  - Forward release (rule 8): FWD_GETS -> owner downgrades E/M to S and sends DATAFWD; FWD_GETM ->
    owner downgrades E/M to I and sends DATAFWD. No PUTS/PUTM on the forward path.
  - Conflict eviction (ruling B2): if the incoming line's set is full, the victim is released
    BEFORE the miss request is issued — dirty (M) -> PUTM and wait for PUTACK; clean (S/E) -> PUTS
    (E waits for PUTACK, S does not). It is a sub-step of the miss transient: the L1 stays in
    IS_D/IM_D, no second transient, no MSHRs. PUTM/PUTS and the later GETS/GETM both travel on
    VC0, so per-VC FIFO ordering preserves release-before-miss at the source.
  - Receptivity (Premise R): an L1 with an outstanding miss still services INV/DATA/INVACK/FWD for
    other lines immediately.
  - Single-exit directory FSMs: DIR_MEM_WAIT, DIR_FWD_WAIT and DIR_INV_WAIT each exit only on
    UNBLOCK; DIR_EVICT is entered only from DIR_MEM_WAIT.
  - Age escape threshold 5 rounds; the output switch arbiter is port-granular, never VC-aware.
  - DMA tile: gated on the Week-8 gate exit, 4x4 simulation only. No DMA tile, DMA signal or DMA
    path in the 2x2 build.
